# Report Quality Gate

Use this to keep first contact useful and conservative.

## First Screen

- project/component:
- affected version or commit:
- boundary:
- observed impact:
- validation level:
- non-claims:

## Required Sections

- [ ] Summary.
- [ ] Affected component and version.
- [ ] Security boundary.
- [ ] Observed behavior.
- [ ] Expected behavior.
- [ ] Root cause summary.
- [ ] Evidence summary.
- [ ] Suggested validation or defensive note.
- [ ] Non-claims.

## Tone

- [ ] One primary vulnerability sentence.
- [ ] Conservative impact language.
- [ ] No bounty, CVE, or timing pressure in first contact.
- [ ] No unexplained AI/tool reference.
- [ ] No scanner-like output dump.

## Maintainer Five-Minute Action

Choose one:

- understand the claim;
- request validation material;
- review a small test or patch;
- route to the security team;
- close or downgrade with clear reason.
